# 사진 넣는 곳

여기에 아래 이름 그대로 넣으면 청첩장에 바로 나옵니다.
파일이 없는 자리는 번호만 보이고, 레이아웃은 깨지지 않습니다.

| 파일명      | 들어가는 자리                |
|-------------|------------------------------|
| `cover.jpg` | 표지 (세로 3:4)              |
| `01.jpg`    | 갤러리 왼쪽 큰 칸 (정사각형) |
| `02.jpg` ~ `07.jpg` | 갤러리 작은 칸 (정사각형) |

## 파일 조건

- **형식**: `.jpg` (아이폰 HEIC은 브라우저가 못 읽습니다. 변환해서 넣으세요)
- **크기**: 긴 변 1600px 정도. 그보다 크면 폰에서 느려집니다
- **용량**: 장당 500KB 이하, 전부 합쳐 5MB 이하 권장
- **잘림**: 표지는 세로 3:4, 갤러리는 정사각형으로 가운데를 기준으로 잘립니다

넣은 뒤 `git add . && git commit && git push` 하면 2분 안에 사이트에 반영됩니다.
